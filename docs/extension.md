# 扩展点说明

## 数据接入
- **事件摄取**：新增 Kafka/Flink 连接器；通过配置新增 topic 即可加入新的分馆或外部合作方数据。
- **批处理**：在 ETL 流程中增加校验/清洗步骤；可插入自定义 UDF 处理特殊字段（如多语言分类）。
- **外部 API**：为第三方目录系统（ILS）或数字资源平台实现适配器，统一映射到内部事件模型。

## 指标与分析
- **自定义指标**：在聚合管线添加新指标（如人均借阅时长、逾期率），并在 `/stats/overview` 增加字段暴露。
- **报表/导出**：增加 `/reports/*` 路由生成 CSV/Parquet；结合预签名 URL 或对象存储加速下载。
- **预测/推荐**：接入模型服务，提供热门书籍预测、补货建议等；通过队列异步调用以避免阻塞主链路。

## 平台能力
- **多租户**：在数据表添加 tenant_id，并在查询层注入过滤；缓存键也带上租户前缀。
- **审计/合规**：外挂审计 sink（SIEM/数据留存）；对 API 请求启用细粒度审计记录。
- **运维自动化**：增加 IaC（Terraform/Helm）模板，标准化网络、证书、监控配置。

## UI 扩展
- **仪表盘**：可接入 Superset/Metabase；或通过前端组件库（AntD/Material UI）构建自定义界面，复用现有 API。
- **自助查询**：新增 `/query` 端点，允许经过授权的分析师提交 SQL/DSL，并在沙箱中执行。
