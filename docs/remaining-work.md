# 待完成功能清单

本列表汇总当前仍未完成且建议补充的工作，便于后续迭代与验收。按照业务优先级和之前讨论的顺序组织。

## 1. 权限与角色完善
- 前端提供用户/角色管理页：新增用户、修改角色、重置密码（仅 ADMIN）。
- 审计日志：记录登录、借阅新增/续借/归还、角色变更等操作，提供查询接口和前端列表。
- 按角色控制 UI：菜单、按钮、批量操作均需隐藏或禁用（VIEWER 只读）。

## 2. 借阅流程深化
- 前端联调续借与罚金显示：展示续借次数上限、逾期天数与罚金；续借/归还后刷新列表。
- 定时任务：每日标记逾期并计算罚金；可通过配置开关启用。
- 规则化配置：续借次数上限、借期、罚金规则改为配置项并在文档中说明。

## 3. 数据导入导出与批处理
- 导入：支持 CSV/Excel 批量导入读者、图书、借阅记录，带字段校验和失败行反馈。
- 批量操作：借阅记录批量归还、批量软删除，前端表格支持多选与批量提交。
- 导出：在现有 CSV 基础上增加 Excel 导出与前端筛选弹窗入口。

## 4. 统计与大屏
- 新指标：人均借阅、热门作者榜、周几/小时热力图、品类周转率等接口。
- 大屏模式：全屏自适应 ECharts、轮播榜单、定时刷新（可基于现有统计接口或新增大屏专用接口）。

## 5. 工程与运维
- CI/CD：添加 GitHub Actions（或其他）流水线，执行后端/前端的 lint、test、build。
- 容器化：编写后端、前端 Dockerfile 及 docker-compose（含 MySQL、Redis、前端服务），提供部署文档。
- 日志与监控：trace-id、慢查询/接口耗时统计，关键操作报警（可对接钉钉/飞书或邮件）。

## 6. 联调与体验优化
- 前端：完善错误提示与 loading、筛选参数回显、导出按钮、表格列宽/排序；大屏截图占位。
- 后端：补充统计、RBAC、借阅流程等关键路径的自动化测试（可选 Testcontainers/H2）。

## 里程碑建议
- **M1：权限与借阅流程联调完成**（项 1-2 的核心能力落地）。
- **M2：导入导出与批处理可用**（项 3）。
- **M3：统计扩展与大屏上线**（项 4）。
- **M4：工程化收尾**（项 5-6 完成，提供文档与截图）。
